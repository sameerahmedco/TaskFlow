# TaskFlow v3 — Features

## Tasks and projects

- My Work, project task lists, Kanban boards, calendars, timelines and recurring tasks.
- Task details, subtasks, dependencies, estimates, due dates, priorities, assignees, labels and checklists.
- Bulk editing, same-team task copying, task templates, CSV import and reporting exports.
- Project overview, portfolio, milestones, risks, decision tracking, status updates, saved searches and priorities.

## Team collaboration

- Team chat, direct messages, announcements, comments, threaded replies, edited-comment indicators and mentions.
- Inbox filtering and bulk read/unread actions, task watchers and notifications.
- Review requests and manager decisions, with review history and pending-review status protection.
- Private task attachments with production malware-scanning requirements.

## Team operations

- Timers, worklogs, timesheets and approvals, workload planning and time reports.
- Time-off requests, half days, team holidays, custom workweek, availability and leave balances.
- Administrator, manager and member roles, invitations, member directory, MFA, password recovery and audit history.

## Interface

- Compact project sidebar, nested navigation, accessible page switcher and responsive mobile layouts.
- Default Light appearance, plus Dark, System, Ocean, Forest, Lavender, Sunset, Midnight, Charcoal and Black/OLED.
- Compact and Comfortable density settings; task details with Details, Checklist, Files & activity, and Discussion tabs.

## Runtime and hosting

- PHP and MySQL, with plain JavaScript/CSS and no application build pipeline.
- First-run setup wizard, versioned migration scripts and administrator CLI tools.
- One organization per deployment. Uploads require configured private storage and production ClamAV scanning. See [deployment](DEPLOYMENT.md) and [security](../SECURITY.md).
